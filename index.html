Eurostat Migration Visualization

This project visualizes the migration dynamics in the Europe region using interactive flow networks and statistical charts.

Interaction

To display a visualization, click on any country colored . Upon click, the flow network will appear for the selected country, displaying migration flows with available partner countries. Hover over another country to highlight the migration dynamics between these two countries with respect to others.

Visual Encoding

The flow network encodes key data dimensions:

  • Migration Volume: Encoded by particle speed—faster particles indicate higher migration volume.
  • Gender Distribution: The color gradient of the flow lines represents the male/female ratio:
    • Male
    • Female
    • No Gender Data

Controls & Analysis

Users can switch the view between Immigration and Emigration by clicking the radio button at the bottom right. The migration trend over time can be examined using the time slider at the bottom.

Additional statistics can be viewed by pressing the statistics button at the bottom left corner. These statistics include:

  • Time series of total migration for the selected country.
  • Comparison of the selected country's GDP with top migration partners.
  • Breakdown of migration by partner countries and age groups (where data is available).
