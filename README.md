# Eurostat Migration Visualization

This project was developed as part of a data visualization course.

It visualizes migration dynamics in Europe with an interactive map (flow network) and a statistics overlay built with D3.js.

This project is hosted on GitHub Pages and can be viewed here:
https://shbutkhuzi.github.io/eurostat-vis/
