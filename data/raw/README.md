# Raw data files

Raw data files used in the analysis:

- [estat_migr_imm5prv.csv](estat_migr_imm5prv.csv)  
    Immigration by age group, sex and country of previous residence.

- [estat_migr_emi3nxt.csv](estat_migr_emi3nxt.csv)  
    Emigration by age group, sex and country of next residence.

- [nama_10_gdp.csv](nama_10_gdp.csv)  
    GDP and salary data.


Each dataset is downloaded and pre-processed using the `get-all-data.sh` script located in the same directory.
